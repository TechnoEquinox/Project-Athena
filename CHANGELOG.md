# Changelog

## v0.1.0
- Public release of the project.

## v0.1.1
- Fixed an issue where the chart sizing on the dashboard was too compact, causing data to be unreadable.
- Added example screenshots to the README.md

## v0.2.0
- Added installer scripts and tests to facilitate setting up the project and configuring it out of the box. 

## v0.3.0
- Added backup and restore functionality, with the option to also save backups to a connected USB flash drive
- Added Uninstall scripts to the project

## v0.4.0
- Added the Athena server agent that handles server adminstration tasks
- Added a Maintenance panel on the Admin page that controls the server agent, allowing admins to see server health, run server and athena updates, and make backups

## v0.4.1
- Formatting fixes in the Maintenance tab
- Added Athena project size, and Athena database sizes to the Pie Chart on the Maintenance tab
- Added missing entries to filter from on the audit log
